# Journey Map Quality Checklist

Do not share, publish, or claim completion until every applicable item passes.

## Pre-synthesis evidence-ready gate

Run before deriving phases, patterns, opportunities, or journey claims:

- [ ] Evidence records are atomic and use unique stable IDs.
- [ ] Every record satisfies its `E` / `I` / `A` / `G` contract: source for `E`,
      supporting IDs + confidence for `I`, validation question/method for `A`, and impact +
      closure action for `G`.
- [ ] No emotion is labeled `E` without direct expression or valid measurement.
- [ ] Every quantified record includes population, numerator, denominator, date/window,
      exclusions, deduplication rule, and caveat.
- [ ] Every GitHub-derived record cites the direct supporting issue or exact comment permalink,
      and a reviewer has confirmed that source supports the claimed actor/date/product signal.
- [ ] Every join reconciles source total = matched + unmatched and describes unmatched
      populations; row multiplication and unresolved duplicate keys are blocked.
- [ ] Feasible structural checks passed. Semantic support and privacy were reviewed rather than
      inferred from validator success.

## Scope and structure

- [ ] The map contains exactly one actor and one scenario.
- [ ] The actor's goal, journey start, journey end, and product/lifecycle scope are explicit.
- [ ] The map is labeled current, future, or hybrid.
- [ ] Phases come from evidenced transitions, not a required phase count.
- [ ] The core rows cover goals, actions, touchpoints, thoughts, emotions, pains, needs,
      opportunities, and evidence/confidence.

## Evidence integrity

- [ ] Every `E` claim traces to a stable evidence ID and source inventory record.
- [ ] Every `I` claim cites supporting evidence and carries confidence.
- [ ] Every `A` is visibly a hypothesis and has a validation question and method.
- [ ] Every `G` states its impact and the action needed to close it.
- [ ] The pre-synthesis emotion rule still holds in the final map.
- [ ] Derivatives trace to underlying sources and are not double-counted.
- [ ] Account families, repeated interviews, and repeated mentions follow the stated
      deduplication unit.
- [ ] Minority and contradictory evidence remains visible.
- [ ] Quantified claims include numerator, denominator, date/window, population, exclusions,
      deduplication rule, and caveat.

## Synthesis and actionability

- [ ] Moments of truth are tied to evidence and a consequence.
- [ ] Each opportunity links to an evidenced pain or need and intended outcome.
- [ ] Candidate metrics fit the phase and business objective without implying causality.
- [ ] Current-state evidence and future-state hypotheses are visually separable.
- [ ] The map distinguishes product interaction from the broader lifecycle where relevant.

## Privacy and accessibility

- [ ] All shared content has been reviewed for direct/indirect identification,
      confidentiality, consent, destination access and retention.
- [ ] Source excerpts, attributions, links, metadata, and hidden details are safe for the intended
      audience.
- [ ] Access classes and board permissions match the most restrictive included evidence.
- [ ] Labels, borders, icons, or patterns convey meaning without relying on color.
- [ ] Text is concise, readable, and ordered for scanning.

## Delivery

- [ ] The board or packet includes scope/legend, journey, evidence ledger,
      assumptions/contradictions/gaps, and opportunities/validation plan.
- [ ] A created board has been inspected for correct content, phase order, placement, links,
      truncation, and overlap.
- [ ] If no write path existed, the response does not invent a URL or imply board creation.
- [ ] The map has a version, research cutoff date, owner if known, and next validation checkpoint.
