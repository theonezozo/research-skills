# Research skills

Portable research and visualization skills for AI assistants.

## Skills

Each package works independently and includes its own essential safeguards and
supporting resources. Start with the skill matching the decision you need to make.

| Skill | Purpose |
|---|---|
| [Survey question writer](skills/survey-question-writer/SKILL.md) | Design neutral questions, routing, scales, pretests and proportionate quality controls. |
| [Pricing study designer](skills/pricing-study-designer/SKILL.md) | Select pricing methods and specify instruments, experimental controls and inference limits. |
| [Multi-source research contract](skills/multi-source-research-contract/SKILL.md) | Define joins, deduplication, reconciliation and claim boundaries before synthesis. |
| [Research statistical methodology](skills/research-statistical-methodology/SKILL.md) | Interpret ordinal responses, uncertainty, missingness and multiple comparisons responsibly. |
| [Data visualization](skills/data-visualization/SKILL.md) | Select truthful encodings, accessible presentation and useful chart checks. |
| [JTBD definition creator](skills/jtbd-definition-creator/SKILL.md) | Extract evidence-grounded situations, motivations and outcomes without inventing gaps. |
| [User journey mapping](skills/user-journey-mapping/SKILL.md) | Separate observations, interpretations, assumptions and gaps in a traceable journey map. |
| [Powerful moments curation](skills/powerful-moments-curation/SKILL.md) | Select and frame verified research excerpts for a defined audience and decision. |
| [Outset study designer](skills/outset-study-designer/SKILL.md) | Prepare AI-moderated studies, pilot checks and separately authorized launch runbooks. |
| [PII screening](skills/pii-screening/SKILL.md) | Review privacy, confidentiality, indirect identification and release surfaces. |

## Installation and use

Copy a complete skill directory, including its resources, into a skill location
supported by your assistant. Depending on the host, examples include
`.github/skills/` or `.agents/skills/`. Check your assistant's documentation:
directory discovery and tool access differ. Do not copy only `SKILL.md` when it
links to resources. Reload skills if your host requires it, then ask for the
relevant task or explicitly select the skill.

No credentials, proprietary data, companion skills or vendor tools are required
to read and apply the core methods. Qualtrics, Outset, Marvin and FigJam guidance
is optional and requires current documentation and separately authorized access
for implementation. A draft, checklist or readiness decision is not permission
to recruit, spend, upload data, modify live systems or publish.

Examples are hypothetical unless explicitly attributed to a public source.
They are not customer findings or validated instruments. Public citations are
references, not bundled copies of third-party works or endorsements.

## Limitations

Static package checks do not establish research validity, legal compliance,
accessibility conformance or agent effectiveness. Review the content and
intended use before relying on it. Vendor capability statements are dated
snapshots; recheck current documentation before use.
